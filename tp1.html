Introduction

Le développement web est l'ensemble des activités liées à la création et la maintenance de sites web. Il englobe un large éventail de compétences et de technologies qui évoluent constamment pour répondre aux besoin changeants de l'environnement numérique. De nos jours, le développement web joue un role crucial dans la création d'une présence en ligne robuste our les individus et les entreprises.





Les fondamentaux du développement web

  1. HTML
    • Base de la structure d'une page web
    • utilisé pour définir la structure du contenu
  2. CSS
    • gére la présentation et l'apparence du site
    • permet la mise en page, la couleur et le design
  3. JavaScript
    • Language de script coté client
    • ajoute l'interactivité et la dynamique aux pages web
